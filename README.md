# Antonio Di Fiore — UX/UI Portfolio

Static multi-page portfolio for the Start2impact HTML/CSS project.

## Open locally
1. Unzip this folder.
2. Open `antonio-portfolio` in Visual Studio Code.
3. Open `index.html` in a browser or with the Live Server extension.

## What is included
- Five HTML pages (Home, About Me, Projects, Contact, CV)
- Bootstrap 5 via CDN, custom Sass in `assets/scss/style.scss` and compiled CSS in `assets/css/style.css`
- Responsive layouts, sticky navbar, Flexbox/Grid, favicon, Open Graph tags, required form fields
- Project mockup images, and an explicitly marked placeholder for your personal photo

## Before submitting
- **Contact form is intentionally disabled**: static GitHub Pages does not process form submissions. Connect a provider such as EmailJS or Formspree and enable the button only after testing.
- Replace generic social destinations with your actual profile links.
- Add your real portrait and any original Figma screenshots/project evidence.
- Verify all CV dates, professional claims and project details.
- Open Graph image is currently SVG. For best sharing compatibility export it as PNG/JPEG, publish an absolute URL and add `og:url`.
- Use a Sass compiler (for example Live Sass Compiler) to rebuild CSS after changing SCSS. The initial CSS is already provided.
- Check all pages and responsive breakpoints; upload repository to GitHub, enable GitHub Pages and test the public URL.
- Create the professor-required PDF explaining design choices and linking to the repository and live site.

## Note
The design is an implementation based on shared references, not an exact pixel-by-pixel Figma export.
